# OCTOPLUS TTL外触发与单线参数配置说明

## 1. 6pin接口定义
OCTOPLUS 的 `Power and IO` 接口为 6pin Hirose，定义如下：

| Pin | 信号 | 说明 |
| --- | --- | --- |
| 1 | `PWR` | 相机供电，`6-15V DC` |
| 2 | `GPO` | 输出，可用于调试 |
| 3 | `GPO` | 输出，可用于调试 |
| 4 | `GND` | 地 |
| 5 | `GPI` | 触发输入 |
| 6 | `GPI` | 触发输入 |

TTL 模式下只用到 `Pin4` 和 `Pin5`。

## 2. TTL接线方法
### 2.1 只接外部触发
```text
外部TTL_OUT  ----> Pin5 (GPI)
外部GND      ----> Pin4 (GND)
Pin6         ----> 悬空
```

### 2.2 外部触发 + 6pin供电
```text
+6~15V       ----> Pin1 (PWR)
电源GND      ----> Pin4 (GND)
外部TTL_OUT  ----> Pin5 (GPI)
外部GND      ----> Pin4 (GND)
Pin6         ----> 悬空
```

注意事项：

- `GPI` 最大输入电压为 `6V`
- TTL 模式下 `Pin6` 不接
- 外部触发器和相机必须共地
- `Pin2/Pin3` 是 `GPO` 输出，不是触发输入

## 3. 关键寄存器
所有时间寄存器步进均为 `0.01 us`，换算公式如下：

```text
寄存器值 = 时间(us) * 100
时间(us) = 寄存器值 / 100
```

| 地址 | 名称 | 说明 |
| --- | --- | --- |
| `0x12100` | `Line period` | 单线时间 |
| `0x12104` | `Line period min` | 最小单线时间，只读 |
| `0x12108` | `Exposure time` | 曝光时间 |
| `0x12114` | `Exposure time min` | 最小曝光，只读 |
| `0x12118` | `Exposure time max` | 最大曝光，只读 |
| `0x1210C` | `Trigger mode` | 触发模式 |
| `0x1211C` | `Line/Frame trigger filter duration` | 线/帧复用触发判定阈值 |
| `0x12120` | `GPI format` | 输入格式，TTL 设为 `0` |
| `0x12124` | `GPI state` | 输入状态，只读 |
| `0x12128` | `Trigger frame line number` | 每帧行数 |
| `0x12110` | `Trigger missed` | 丢触发计数 |
| `0x12184` | `Trigger Jitter` | 外触发抖动补偿 |

## 4. 触发模式说明
### 4.1 外部单线触发
- `0x1210C = 2`：外部单线触发，可编程曝光
- `0x1210C = 3`：外部单线触发，最大曝光

这两种模式下：

- 单线时间不是 `0x12100` 决定的
- 单线时间 = 外部 TTL 脉冲周期
- 相机按外部 TTL 的上升沿计线周期

例如外部 TTL 频率为 `50 kHz`：

```text
单线时间 = 1 / 50 kHz = 20 us
```

### 4.2 外部帧触发 + 内部行触发
- `0x1210C = 6`：外部帧触发，内部行触发，可编程曝光
- `0x1210C = 7`：外部帧触发，内部行触发，最大曝光

这两种模式下：

- `0x12100` 决定单线时间
- `0x12128` 决定每帧行数
- 外部 TTL 只负责启动一帧

## 5. 单线时间与曝光时间关系
常用约束如下：

- `Exposure time min` 通常约为 `1.3 us`
- `Exposure time max` 通常约为 `Line period - 0.7 us`

因此如果单线时间为 `20 us`，最大曝光通常约为：

```text
20.0 us - 0.7 us = 19.3 us
```

在外部单线触发模式下：

- 模式 `2`：曝光由 `0x12108` 设置
- 模式 `3`：曝光自动等于 `外部周期 - 0.7 us`

在内部行触发模式下：

- 单线时间由 `0x12100` 设置
- 曝光由 `0x12108` 设置

写完 `0x12108` 后，建议立即读回一次，因为相机可能会自动修正到最近的合法值。

## 6. 最小参数说明
### 6.1 最小曝光时间
最小曝光时间应以相机当前返回值为准，读取：

- `0x12114` `Exposure time min`

手册中常见模式下：

- 内部单线触发 `0/1`：最小曝光通常为 `1.3 us`
- 外部单线触发 `2/3`：最小曝光通常为 `1.3 us`
- 外部帧触发 + 内部行触发 `6/7`：最小曝光通常为 `1.3 us`

换算为寄存器值通常是：

```text
1.3 us = 130
```

注意：

- 真正可用下限以 `0x12114` 读回值为准
- 最大曝光受 `Line period - 0.7 us` 限制

### 6.2 最小单线时间
最小单线时间读取：

- `0x12104` `Line period min`

这个值不是固定常数，而是和当前模式、抖动补偿等配置相关：

- 内部行触发模式下，`0x12100` 不能小于 `0x12104`
- 外部单线触发模式下，外部 TTL 周期不能小于 `0x12104`
- 如果外部触发周期小于 `0x12104`，新触发会被丢弃

因此：

- 最小单线时间 = `0x12104 / 100 us`
- 最小单线频率 = `1 / 最小单线时间`

例如如果读到：

```text
0x12104 = 1000
```

则表示：

```text
最小单线时间 = 10.00 us
最大线频 = 100 kHz
```

### 6.3 最小触发时间
“最小触发时间”要区分三种情况：

1. 外部单线触发 `0x1210C = 2/3`
2. 外部帧触发 + 内部行触发 `0x1210C = 6/7`
3. 线/帧复用单信号触发 `0x1210C = 4/5`

#### 外部单线触发 `2/3`
手册没有单独给出固定的“最小高电平脉宽”数值，但明确要求：

- 相邻有效触发上升沿的周期不能小于 `0x12104`

因此工程上应这样理解：

- 最小触发周期 = `Line period min`
- 外部 TTL 高低电平都要稳定，保证相机能可靠识别上升沿

#### 外部帧触发 `6/7`
手册明确给出：

```text
Frame trigger pulse width > 10 ns
```

并且：

```text
Frame period > 10ns + (Line number + 1) * Line period
```

也就是说：

- 最小帧触发脉宽：`大于 10 ns`
- 最小帧触发周期：`大于 10ns + (行数 + 1) × 单线时间`

#### 线/帧复用触发 `4/5`
这种模式下线脉冲和帧脉冲共用一根 GPI，由 `0x1211C` 决定判定阈值：

- `pulse width < 0x1211C`：识别为线触发
- `pulse width > 0x1211C`：识别为帧触发

手册给出的最小阈值为：

```text
0x1211C >= 250 ns
```

因此可理解为：

- 最小线/帧区分时间阈值：`250 ns`
- 复用模式下线脉冲宽度必须小于阈值
- 帧脉冲宽度必须大于阈值

### 6.4 最小值总结
| 参数 | 获取方法 | 常见/已知下限 |
| --- | --- | --- |
| 最小曝光时间 | 读 `0x12114` | 常见为 `1.3 us` |
| 最小单线时间 | 读 `0x12104` | 与模式有关，不是固定值 |
| 最小触发周期 | 由 `0x12104` 决定 | 外部单线触发时不能小于 `0x12104` |
| 最小帧触发脉宽 | 手册固定约束 | `> 10 ns` |
| 线/帧判定阈值最小值 | `0x1211C` | `250 ns` |

## 7. 典型配置
### 7.1 TTL外部单线触发
目标：

- 外部 TTL 频率：`50 kHz`
- 单线时间：`20 us`
- 曝光：`8 us`

配置：

- 接线：`Pin5 = TTL`，`Pin4 = GND`
- `0x12120 = 0`
- `0x1210C = 2`
- `0x12108 = 800`

说明：

- 单线时间由外部 TTL 周期决定，不需要写 `0x12100`
- 外部 TTL 必须稳定为 `20 us` 周期

### 7.2 TTL外部帧触发 + 内部行触发
目标：

- 单线时间：`20 us`
- 曝光：`8 us`
- 每帧：`1024` 行

配置：

- 接线：`Pin5 = TTL`，`Pin4 = GND`
- `0x12120 = 0`
- `0x1210C = 6`
- `0x12100 = 2000`
- `0x12128 = 1024`
- `0x12108 = 800`

说明：

- 外部 TTL 只负责开一帧
- 每帧内部按照 `20 us` 的行周期跑满 `1024` 行

## 8. SDK配置方法
Linux SDK 通过以下接口直接读写寄存器：

- `USB3_ReadRegister()`
- `USB3_WriteRegister()`

4 字节寄存器使用小端格式。建议封装如下：

```c
static int wr32(CAM_HANDLE h, unsigned long addr, uint32_t v) {
    size_t sz = 4;
    return USB3_WriteRegister(h, addr, &v, &sz);
}

static int rd32(CAM_HANDLE h, unsigned long addr, uint32_t *v) {
    size_t sz = 4;
    return USB3_ReadRegister(h, addr, v, &sz);
}
```

### 8.1 外部单线触发示例
```c
wr32(h, 0x12120, 0);    // TTL
wr32(h, 0x1210C, 2);    // External line trigger, programmable exposure
wr32(h, 0x12108, 800);  // 8.00 us
rd32(h, 0x12108, &val); // 读回确认
```

### 8.2 外部帧触发示例
```c
wr32(h, 0x12120, 0);     // TTL
wr32(h, 0x1210C, 6);     // External frame trigger + internal line trigger
wr32(h, 0x12100, 2000);  // 20.00 us
wr32(h, 0x12128, 1024);  // 1024 lines
wr32(h, 0x12108, 800);   // 8.00 us
```

## 10. 推荐配置顺序
### 10.1 外部单线触发
1. 接好 `Pin5` 和 `Pin4`
2. 写 `0x12120 = 0`
3. 写 `0x1210C = 2`
4. 读 `0x12104`、`0x12114` 和 `0x12118`
5. 确认外部 TTL 周期不小于 `0x12104`
6. 写 `0x12108 = 目标曝光`
7. 读回 `0x12108`
8. 开始采集
9. 输入外部 TTL 脉冲

### 10.2 外部帧触发
1. 接好 `Pin5` 和 `Pin4`
2. 写 `0x12120 = 0`
3. 写 `0x1210C = 6`
4. 读 `0x12104`
5. 写 `0x12100 = 单线时间`，并保证不小于 `0x12104`
6. 写 `0x12128 = 每帧行数`
7. 读 `0x12114` 和 `0x12118`
8. 写 `0x12108 = 目标曝光`
9. 读回 `0x12108`
10. 开始采集
11. 输入外部帧触发脉冲

## 11. 调试建议
- 读 `0x12124` 检查 GPI 是否有电平变化
- 读 `0x12110` 检查是否存在丢触发
- 外触发模式下，LED 慢闪绿表示相机正在等待触发
- 可将 `Pin2` 或 `Pin3` 的 `GPO` 接示波器，和 `Pin5` 输入做对比

## 12. 常见问题
### 12.1 没有触发
- 检查 `Pin5` 是否接到 TTL 信号
- 检查 `Pin4` 是否共地
- 检查 `0x12120` 是否为 `0`
- 检查 TTL 电平是否超过 `6V`

### 12.2 曝光写入后不一致
- 先读 `0x12114` 和 `0x12118`
- 再写 `0x12108`
- 写后读回确认

### 12.3 触发丢线或丢帧
- 检查外部 TTL 周期是否过快
- 检查曝光是否已经接近 `Line period - 0.7 us`
- 检查单线时间或外部触发周期是否小于 `0x12104`
- 必要时使用 `0x12184` 增加抖动余量
