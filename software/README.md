# Software

## RK3588 Qt Panel

Current source:

```text
software/rk3588_qt_panel_current/
```

The panel controls/display the LC-OCT acquisition flow, sends image data to the
FPGA over PCIe/XDMA, displays raw and FPGA-processed views, and opens YOLO/RKNN
analysis video when requested.

## YOLO/RKNN Analysis

Current script and model:

```text
software/rk3588_yolo_analysis_current/
```

The active model is:

```text
yolov8n_fpga1_full650_best.rknn
```

The analysis input must be FPGA processed cache images generated by the current
panel/FPGA flow.
